# LocalMind 工具中心玻璃工作台设计

## 目标

将现有 LocalMind 桌面应用的工具入口重塑为已确认的三栏工具中心：左侧保留应用级导航和知识库/最近对话，中间展示可调用工具卡片，右侧展示选中工具详情。实现只调整 UI 组织和交互，不改变现有模型、知识库检索、计算器和工具路由的业务逻辑。

## 视觉与布局

- 采用深色墨蓝背景、半透明面板、细微冷青高光和统一圆角，延续 LocalMind Glass Workspace 视觉稿。
- 左栏保留品牌、模型选择、模型状态以及“对话 / 知识库 / 工具”主导航；“工具”激活时，下方显示“我的知识库”和“最近对话”两组应用级内容。
- 中栏顶部为“工具中心”和说明文字，提供搜索、分类筛选和网格/列表切换；工具以 2×3 卡片网格展示，选中卡片有冷青描边和轻微高光。
- 右栏为固定宽度的“工具详情”面板，展示名称、启用状态、用途、能力标签、示例和最近调用记录，并提供配置/测试调用入口。
- 三栏之间有稳定分隔线；窄窗口下优先保证中栏可读，右栏仍可折叠，不产生水平滚动条。

## 交互

- 点击左侧主导航切换到已有页面；点击工具进入工具中心并默认选中第一个启用工具。
- 搜索和分类筛选只影响中栏卡片，不改变已注册工具。
- 点击工具卡片同步更新右侧详情。
- 工具状态、描述、能力和最近调用记录从现有工具注册/路由数据读取；没有记录时显示明确空状态。
- 右侧折叠按钮位于面板右上角，折叠后保留可发现的展开箭头。

## 复用边界

- 复用 `ToolRouter`、现有工具注册表、计算器工具和主窗口页面切换机制。
- 不在本次工作中修改模型加载、知识库索引、对话协议或工具执行安全策略。
- 如现有代码缺少工具元数据，补充轻量的展示适配层和默认中文描述，不改变执行接口。

## 验收标准

1. 工具中心启动后显示三栏布局，左侧下方是知识库与最近对话，而不是工具分类列表。
2. 中栏至少能展示现有已注册工具，支持搜索、分类筛选和卡片选择。
3. 右栏能根据选中卡片更新详情，折叠/展开状态清晰，内容不被裁切。
4. 原有对话、知识库和工具调用仍可进入并工作。
5. 不引入水平滚动条；长中文文本自动换行。
6. 运行现有 UI smoke tests 和相关单元测试，并完成一次桌面启动检查。
