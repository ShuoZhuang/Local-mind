# 知识库管理界面重设计

## 目标

将当前“上传文件 + 状态列表”的知识库页面升级为可长期管理多个文档的工作台。用户可以查看文档、选择分段策略、确认片段效果，并安全地重新处理或删除文档。

本设计不接入云端服务；文档、模型、向量和状态继续仅保存在本机。

## 已确认的界面结构

页面采用“管理看板 + 右侧抽屉”的布局。

- 主区域是知识库看板：知识库名称、文档数、片段数、索引状态、搜索/筛选和文档列表。
- 点击“添加文档”后，右侧抽屉显示导入向导：选择文件 → 选择分段策略 → 确认并建立索引。
- 点击已有文档后，右侧抽屉显示文档详情，不离开文档列表。
- 文档列表为唯一的状态入口：已索引、处理中和失败状态都直接显示在对应行。

## 文档详情

右侧详情抽屉包含：

- 文件名、格式、大小、来源路径、导入时间；
- 索引状态和片段数量；
- 实际采用的分段策略与参数快照；
- 前几个片段的预览；
- “查看全部片段”入口；
- “重新处理”与“删除”操作。

“查看全部片段”打开独立页面，支持查看片段文本、编号、页码、标题路径和来源信息。

点击“重新处理”时，必须先说明影响范围：旧片段和旧向量会被删除，然后按新策略建立索引。用户确认后才执行。

## 分段策略

软件提供一套全局可复用的分段策略库；每次上传或重新处理文档时由用户选择。系统记住上一次使用的策略与参数作为下次默认值，但每份文档保存自己的实际配置快照。

### 自动分段与清洗

自动识别段落、标题和空白；当片段超过最大长度时按自然边界优先拆分。适合结构不明确的普通文档。

### 自定义分段

用户可选择或输入分隔符，并设置：

- 分隔符预设：换行、两个换行、中文句号、中文逗号、英文句号、英文逗号、中英文问号、自定义；
- 自定义分隔符输入框；
- 最大长度（明确以“字符”为单位显示）；
- 重叠度百分比；
- 预处理选项：规范连续空格/换行/制表符、删除 URL 和邮箱、保留标题和页码。

界面需显示预计片段数量和少量片段预览。

### 按层级分段

按文档结构产生片段，并将标题路径加入片段元数据：

- Word：识别标题 1、标题 2 等标题样式；
- Markdown：识别 `#`、`##`、`###` 等标题；
- PDF：尝试识别“第一章”“1.1”“一、”等编号标题；
- 未识别到可信层级时，自动退回“自动分段与清洗”，并向用户显示提示。

标题路径示例：`第一章 网络安全基础 > 1.2 网络攻击类型`。

## 技术结构

分段实现采用策略模式，便于增加新规则而不重写导入流程：

```text
ChunkingStrategy
├── AutoChunker
├── CustomChunker
└── HierarchicalChunker
```

导入流程：

```text
上传或重新处理
→ 解析原文件
→ 选择 ChunkingStrategy
→ 生成片段与元数据
→ Embedding
→ Chroma upsert
→ 保存文档记录和策略快照
```

每个文档记录至少包含：文件哈希、原始文件路径、知识库 ID、状态、片段数、策略 ID、策略参数快照、错误信息、创建/更新时间。

每个片段保留：文件哈希、文档 ID、片段编号、页码、来源路径、标题路径、文本内容。

## 错误与状态

- 处理中：显示当前阶段和百分比，例如“解析中”“向量化中”“保存中”。
- 成功：显示片段数量和完成时间。
- 失败：直接显示失败状态；详情抽屉显示完整错误原因和“重试”入口。
- 策略回退：层级识别失败时显示“未识别到明确层级，已使用自动分段”。

## 不在本次范围内

- 在线协作或云端同步；
- 直接编辑原始文档；
- 批量导入和批量重处理；
- 关键词/向量混合检索的高级配置。

## 验证计划

- 单元测试三种分段策略、预设分隔符和层级回退；
- 测试策略参数快照与文档元数据保存；
- 测试重新处理会先删除旧向量再写入新向量；
- 测试处理中/成功/失败状态转换；
- UI 测试：抽屉在“导入”和“文档详情”之间切换，查看全部片段入口可用；
- 手工验证：DOCX、Markdown、PDF 各导入一份，检查标题路径与检索引用。
