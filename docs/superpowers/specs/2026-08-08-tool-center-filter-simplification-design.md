# 工具中心筛选项精简设计

## 目标

工具中心的筛选栏只呈现当前产品需要的三种视图：`全部`、`已启用` 和 `本地能力`。移除按历史分类 `计算`、`检索`、`文档` 筛选的入口。

## 范围与行为

- 仅修改工具中心筛选栏和与其直接对应的筛选判断。
- `全部` 显示可调用工具和本地能力；`已启用` 只显示已接入的可调用工具；`本地能力` 只显示本地能力卡片。
- 搜索、卡片重排、工具详情和 MCP Server 管理保持现有行为。
- 不改动 `data/` 内的用户知识库数据，也不改变工具或能力的分类元数据。

## 实现方式

在 `ToolCenterPage` 创建筛选按钮时，将类别列表固定为上述三项。筛选逻辑只处理这三种可达状态：默认全部、已启用工具、本地能力。删除旧分类的匹配条件，避免 UI 中不存在的筛选状态继续影响显示。

## 测试与验证

先在 `tests/test_tool_center.py` 增加测试，验证筛选按钮集合准确为三项，并验证三种筛选状态的可见工具/能力集合。该测试应先失败，再完成最小实现使其通过。随后运行工具中心测试，以及 GPU Python 环境下的完整 pytest 回归。

## 风险控制

工作区已有未提交的 MCP 与界面改动。本次只触及筛选按钮、相应筛选逻辑及目标测试，不覆盖或重置任何现有改动。
